Raspberry Pi と各デバイスを Bluetooth 接続する際、各デバイス側から Raspberry Pi に接続しようとしたときに接続できないことがあるんだけど、これの法則が分かった気がする。

Bluetooth デーモンを再起動したあと、最初の接続は Raspberry Pi からじゃないと接続できないっぽい。毎朝 Bluetooth デーモンが再起動されるようになっているが、一番最初は Raspberry Pi 側から接続する必要がある。これはデバイス単位で当てはまるようで、Bluetooth デーモン再起動後、Mac に初めて（Raspberry Pi 側から）接続したからといって、iPhone は iPhone 側から接続できるわけではない。ただデーモン再起動後、一度でも Raspberry Pi 側から接続ができていれば、次に再起動するまではそのデバイス側から接続することはできるようだ。

デバイス側から接続できるのであれば面倒がない（Raspberry Pi 側からだと自動実行じゃない限りはコマンドを実行する必要があるしそれに時間がかかるからちょっと面倒）ので、Bluetooth デーモン再起動後、一回だけ Raspberry Pi から接続しておけば、あとは接続チェックをしなくても良いかなと思った。5 分ごとに cron で Bluetooth の接続チェックをすると、そのときに CPU 使用率が上がって音がちょっとプツプツしたりすることがあるので。

# ファイナンシャルプランナーとの会話
今日は 14 時から、例のファイナンシャルプランナーとの話をしてきた。13:55 ごろに店に入ったのだが、30 分前くらいにすでにお店で場所を確保してくれていたようだ。場所が確保できないと思ったと言っていた。まあたぶんこの時間帯だったら大丈夫だとは思うけど、そこまで気遣ってくれるのはありがたいなと思った。

だいたい 1 時間半くらいの会話だったので細かい話は割愛するが、主に以下のことについて話を聞いた。

* 投資信託を始めるべき理由
* 株と投資信託の違い
    * 株
        * 短期売買が基本
        * ある程度資金に余裕がある人がやる
        * ハイリスク・ハイリターン
    * 投資信託
        * 長期保有が基本
        * 少額からでも購入可能
        * ローリスク・ローリターンだが、長期保有するとプラスになる確率が高い
* NISA と iDeCo
* NISA の仕組みや上限金額など
* iDeCo のデメリット
* NISA や iDeCo 以外の投資信託
* 証券会社

話の中でも特に参考になったのが、投資信託はむしろ価値（値段）が下がっているときこそ投資すべきだということだ。株の場合はある程度まとまったお金（たとえば 100 万円〜）を投資する必要があるというリスクがある上に、その会社の業績がずっと下がり続ける可能性もあるし最悪倒産したらすべて失うことになる。だからハイリスク・ハイリターンでなおかつ短期決戦になることが多い（1 つの会社の株を長く持っていればいるほど得をするとは限らない）。

一方で投資信託は長期目線で見ればほぼ間違いなくプラスになることが多いので、1 口の価値が下がっているときこそ多めに買っておいて、高いときに売ればその分利益も大きくなるということだ。株の場合ももちろん基本的な考え方は同じであるのだが、高くなったときに売るといってもいつ高くなるのか分からないし、なんなら下がり続けて結局倒産って可能性もあるから長く保有することが良いとも限らない。

投資信託は長く保有していればそれだけ利益になる可能性が高いので安いときにたくさん買って高くなったら売るということがしやすいということだ。証券会社によって、安いときにたくさん買うみたいなことができない場合もあるが、それができなかったとしても毎月定額で積み立てるだけでも利益が出る可能性は長期で見れば高いということだ。

まあある程度の基本的な知識はあったのだが、今回の話をきっかけに NISA の口座をとりあえず作っておくのはありかなと思った。というのも NISA は来年から新しくなり、従来のものは今年までしか作れないので。まあ従来の NISA の口座を作ったとしても年単位で預けられる限度額が決まっていて、来年からはもう新しく積み立てることはできないので預けられる額は限定的ではあるのだが、とりあえず作る分にはやっておいても損はないかなと思った。

# オンライン英会話 with Barbara
はじめての Barbara さんとのレッスンだった。今日はまだレッスンの予約を入れていなくて、いつもの先生たちのスケジュールだと良い感じの時間帯は空いていなかった。

まずはお互いに軽く自己紹介をした。Barbara さんはアメリカのペンシルベニア州出身で、今はコスタリカに住んでいるらしい。こちらはオーストラリアに行く話をしたので、オーストラリアのどこに行くのかやどれくらい滞在するかなど基本的なことを訊かれた。

それ以外に何を勉強していたのか訊かれたので情報科学について学んでいたと答えた。またエンジニアとして働いていたがオーストラリアに行くために会社をやめた話もした。

あと歯医者の話もした。そのときに Barbara さんの息子さんも歯医者に行って夜寝る前は必ず歯を磨かないといけないと言われたという話を聞いた。ただし全員がそれを怠ると虫歯になるわけではないみたいなことを言っていたので、それは口の中の菌の多さによるからですよねと答えた。残念ながら自分も虫歯になりやすいので毎食後、少なくとも寝る前には必ず磨かないといけない。でも虫歯が見つかってからはちゃんと磨いているという話をした。

後半はどうやったら英語を流暢に話せるかということについてずっと聞いていた。基本的には今まで聞いたことのある内容だが、強調していたのは字幕なしでテレビ番組を観て耳で「聴いて」理解することだと言っていた。字幕があると「見て」理解することになってしまうので、喋れるようにはならない、話せるようになるためには耳で聴いて口で発音することで脳にその回路を定着させるということを言っていた。

そのときにテレビ番組が良いと言っていたのだが、TED Talk はどうかと訊いてみたが、悪くはないがベストではないと言っていた。その理由は、視覚情報と聴覚情報がリンクしないからだ。たとえばコップを持っている人が "a cup" と言っていればその物体が "cup" という発音で表現されるものであるということが紐づく。TED Talk の場合はスピーカーがステージの前で話すだけなので視覚情報がなく脳の回路の定着が乏しいということなのだろう。その視点は今まで持っていなかったので参考になった。

ただ一方で、以前に Max さんと話したとき、彼はむしろ視覚情報のないポッドキャストとかのほうが良いと言っていた。なぜなら視覚情報があると、完全に耳だけで理解できていなかったとしても映像で補完できてしまうからだと言っていた。どっちの意見も理屈は通っているな。まあ今リスニングを毎日やることをノルマとしていないので、まずはそれを再開するところから始めないとな。
