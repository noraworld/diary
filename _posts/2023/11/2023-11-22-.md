ネットワーク制限 (特に夜中の `snorlax.conf`) があるとやはり Kindle 端末で本の詳細ページが読み込めなくなる現象が発生する。しかもこれ、どこかのランダムなタイミングで一覧をすべてキャッシュしているので、ネットワーク制限中でも読み込めることがある (オフライン読み込み) のだが、逆にネットワーク制限中にそのキャッシュを更新しようとしていると、制限が解除されてもしばらく本の詳細が読み込めなくなる。本の詳細だけじゃなくて検索とかもそう。ただし端末本体でネットワークでエラーが発生しているわけじゃなく、ウェブブラウザなどを開くとちゃんと読み込める。

これは困る仕様だな。いつ Kindle ストア (本の詳細ページ等のキャッシュ) 情報がアップデートされるかは全く分からない (完全ランダム) だし、設定を隅々まで確認したがこれを手動で行うものは見つからなかった。唯一、端末を再起動することで確実に更新できるようにはなるのだが、毎晩ネットワーク制限はやってくるので、朝になって毎回再起動するのは現実的じゃないよな。

40 分ほど端末をいろいろいじっていて、以下の手順で条件を変更したときに再び本の詳細が (再起動なしで) 読み込めるようになったのだが、ただの偶然だった可能性もある。

1. Page Refresh を Off から On に変更
2. Airplane Mode を Off から On に変更
3. Dark Mode を Off から On に変更
4. Sync をタップ
5. ホームページの本の詳細をタップ
6. Airplane Mode を Off にするか訊かれるので Yes を選択
7. 直後に Wi-Fi に接続するか訊かれるので Connect を選択

これは引き続き同じ条件で調査する必要があるが、もし単なる偶然だったらもう Kindle 側では打つ手なしだな。Kindle 端末だけネットワーク制限の例外処理を入れるかと思ったけどそれも面倒だし、仮に出来たとしても夜中も読み込めたり本を購入できたりするのはネットワーク制限をしている意図と反する。さて困った。

# Epic Games、本当にクソ
Fall Guys を始めたんだけど、なんかすげえめんどくさいことになった。まず遊ぶためにはアカウントの登録が必須だった。最初に Nintendo アカウントで同意をする必要があった。その次に Epic Games のアカウントでログインする必要があったのだが、これが非常に悪質な罠だった。

アカウントを作るかすでにあるアカウントでログインするかの選択肢があったのだが、Epic Games のアカウントを持っていなかったので新しく作るほうを選んだ。だがそこでは誕生日を入力するだけで ID の設定やメールアドレス、パスワードの登録は一切なかった。

そして最後に Nintendo アカウントと紐付けるみたいな選択が出てきてそれを選択して先に進んだのだが、その直後に、あれ、これもしかしたら Nintendo アカウント経由で Epic Games のアカウントを作ったことになっている？ ということに気づいた。なるべく別のアカウントを使ってログインするっていうのは避けたいのに、なんかそういう説明が一切なく勝手に進んでしまった。

あとから Web で Nintendo アカウント経由でログインしようとしたらメールアドレスやパスワードを設定する画面になった。そこで必要事項を入力してアカウント設定画面に来たら、Nintendo アカウントと連携されたアカウントになっていた。つまり Epic Games では個別のパスワードなどがあるから別に Nintendo アカウントでログインしたっていう感じにはなっていなかった（あくまで Nintendo アカウントと紐付けることで Nintendo Switch では簡易的なログインができるという仕組みだった）ようだ。

しかしその仕組みに気づいたのはあとからで、その時点ではまだそういう仕組みだということに気づいていなかった。そりゃだってややこしすぎるんだから仕方ない。で、ちゃんと独立した形で Epic Games アカウントが使えるように、Nintendo アカウントとの紐づけを解除してこの Epic Games アカウントも削除して、いったんまっさらなアカウントを作ろうとしたのだが、これが悪手だったようだ。

一度紐づけた Nintendo アカウントを解除すると、Nintendo アカウント側でゲームセーブデータを保存することができなくなるというデメリットがあった。アカウントを再接続することはできるが、Nintendo のクラウドに Fall Guys のデータを保存することができなくなる。

間違って解除した場合はすぐにサポートチームへ連絡してくださいというメールが届いていたのでサポートに連絡した。チャットがもう使えない時間帯だったのでメールで送った。

まず強制的にアカウントに登録させられるのもクソだし、一度紐づけを解除すると二度とできなくなるというのもクソ。しかもその仕組みもすごくややこしくて一切説明がない。Nintendo アカウントでログインできる仕組みなのか、それは簡易的なログインの仕組みで、実際には Epic Games アカウントという別のアカウントが作られているのか最初は分からなかった。なんでこんなクソな仕組みになっているんだろうか。非常にモヤモヤとイライラが溜まっている。

とにかく早く連絡をよこせ。そして元通りに戻せ。これで戻せないとか言われたら本当にクソの極みだぞ。

で、自動更新が有効になっているわけだが、実はこのまま自動更新にしておくと、どうやら去年の時点での割引率・プランで自動更新されるらしい。だったら今年のブラックフライデーでプランを追加するのではなく、このままサブスクリプションの自動更新で支払ったほうが良いんじゃないかという結論に至った。

# オンライン英会話 with Heather
レッスンに 30 秒くらい遅れてしまったこととその理由を最初に話した。なんか Cambly ってつながるのに時間がかかるんだよな。あと Cambly が頻繁に UI を変えるので必要なボタンやページ遷移がどこにあるのか分からなくて困ることがあるという話もした。

チューター側の UI や仕様も頻繁に変わっているようなので、まるで私たちが "guinea pig" (モルモット) になった感じだと話していた。この単語、レッスンで遭遇したのはこれで 2 回目だ。以前は Ron が使っていた。最初聞いたとき聞いたことはあるけどなんだか思い出せないとなっていたが、ちょっと時間をおいてから思い出すことが出来た。

使い方は日本語と同じ（日本語でもモルモットを実験対象として見る）なのに、その単語自体が日本語と全く違うので新たに覚えなくてはならなくて混乱するという話をした。

モルモットを "guinea pig" というのに関連して、ウーパールーパーを "axolotl" (`/ˈæk.sə.lɑː.t̬əl/`) というのもその一例だという話をした。最初、"mexican salamander" と言ったのだがどうも Heather さんは何の動物なのか分かっていなかった。自分がそれを説明している間にネットで調べていたらしく、「あー、"axolotl" のことね」と言っていた。つまり "mexican salamander" という言い方はあまり一般的ではない（学術的な？）ようだ。

そして日本ではこれを "wooper looper" と言うということを言ったら、響きが可愛いと言っていた。やっぱり日本語は語彙のセンスが好きだと言っていた。

これはどこかの企業が命名したもので正式な呼び名ではないという話をした。その後、Heather さんがさらに詳しく調べてくれた。

"axolotl" をスペイン語か何か（メキシコだからスペイン語で読む、という現地の言葉を尊重するのは日本語の良さだと思う）で読んだときにそれをカタカナ表記すると「アホロートル」となり（Google 日本語入力でも「アホロートル」と入力すると "axolotl" が変換候補に出てくる）それを当て字にすると「阿呆老頭児」となる。そしてこれの意味が "stupid old fart" になるらしい。これは「ウーパールーパー」という言葉の語源というわけではないと思うが英語ではそういう解説もされているようだ。

そこから日本語の言葉に関する話で「矛盾」という言葉が面白いんじゃないかと思いつきそれについて説明することにした。テキストで「矛盾」と書いて送って、これの意味を翻訳機なしで推測してもらうというちょっとしたゲームをした。矛盾の故事成語について英語で説明して、それで "contradiction" と答えてもらうというものだったが、ちょっと説明が足りなかったか、Heather さんが当てることはできなかった。その後、正解を言ってなるほどと納得してもらえた。

これを発音するときは「ほこ」と「たて」って言うの？ と訊かれたので、訓読みと音読みについての説明をした。訓読みは日本語由来の発音で音読みは中国語由来の発音であること、そしてなぜ 2 つあるのかというと、文字は中国からやってきたけどもともと発音のシステムはあったので、漢字の文字の意味に対して日本語の発音を当てる、ということをすると自ずと 1 つの漢字に 2 つの発音が生まれるという話をした。

でも Heather さん的にはひらがな、カタカナ、漢字の 3 種類の文字のシステムがあることのほうがややこしいみたいだったけど、ひらがなとカタカナはそれぞれ 50 文字しかないから大丈夫、漢字は 2,000 字以上あるから大変だという話をしたら、もうヘッドフォンが外れる勢いでリアクションしていた。

なんでそんな大量の文字を使いこなせるのかと訊かれて、自分でも不思議に思うが小学生のころからずっとやっているからなんじゃないかと答えた。

ここで残り時間が 10 秒くらいになっていて、始めから終わりまで完全に今日の話の流れだけで 30 分経ってしまったので今度からはトピックを最初に目次として伝えてくれと言われた。いや、まあ個人的にはこんな感じで話の流れで会話したほうが楽しいから別にいいんだけどなあと思った。
