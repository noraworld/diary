Netflix を再契約した。そして今日は昼過ぎから日が沈むまで数時間ずっとポケモンでリスニングの練習をしていた。Amazing!

一応、無駄にお金を払い続けないように自動更新はキャンセルしておいた。でもずっと使い続けるのであればその都度更新すればいいし、Netflix の場合はそんな手間じゃないからそれで良いだろう。

さて、今回 Netflix を契約したのは、もちろんそろそろリスニングの練習も日々の習慣に組み込みたいというのが一番大きな理由だが、いろいろと確認したいこともあったからだ。

[Netflix でいろいろ確認する](https://github.com/noraworld/to-do/issues/179)

広告ありの一番安いプランだと、推しの子などの一部のコンテンツが版権の関係上、視聴できないっぽい感じが前回あったんだけど、今確認したら問題なかった。でもこれは正直視聴できないままのほうが良かった。あくまで Netflix は英語の学習として使いたいから、こういう娯楽系のものはなるべく見られないようになっていたほうが良い。まあでもこれは仕方ないな。

次に Language Reactor に関してだが、この拡張機能を有効にしていると YouTube Live の画面が開けなくなるバグは相変わらず存在している。しかし、Chrome の設定で有効にするウェブサイト (ドメイン) を細かく指定できることが分かった。その設定で `https://*.netflix.com/*` のみを有効にすることで、YouTube Live には影響を及ぼさなくなり、結果的にこの問題は解決した。

また、昨日、DeepL の Web 版にログインすることができるようになったと書いたが、これにより逆に API 版が使えなくなってしまっているのではないかという疑惑が浮上した。ということで Netflix で Language Reactor を有効にして DeepL の翻訳機能 (自分で実装したやつ) を確認してみたところ、問題なく使えた。ということで、一つのアカウントで Web 版と API 版、両方が使えるようになったということが分かった。

ただしちょっと実装がバグっていて、Language Reactor が表示したサブタイトルの単語をクリックするとその単語の意味や例文などが表示される UI / UX になっているのだが、それを表示するとそのページをリロードしない限り DeepL の翻訳が表示されなくなってしまうバグを発見した。これはいずれ直したいけど今のところこの機能をそもそもあまり使っていないのでそこまで優先度は高くない。

それよりも、キャラクターの発言ごとに自動で再生が止まる機能をトグルするショートカットを設けているんだけど、これを無効にするほうが重要だと思った。これが有効になっていると結局ずっと再生されっぱなしになっちゃってリスニングの練習というより単純にコンテンツを楽しんでいる感じになっちゃうので。あと手動でこの機能をオフにしたらもとに戻す (5 秒ごとに監視するなどして) 機能も実装したほうが良いかも。

そして、今回一番感動したのが昔 (一番最初に買った) エアマウス・キーボードが再び利用できるということに気づいたことだ。このエアマウス・キーボードは USB レシーバで駆動するので、Mac で使う場合はレシーバが筐体からピョコッと飛び出るかたちになってみっともないし邪魔な上に、USB-C アダプタをかませないといけない。だから使わなくなったら外す作業が発生するので、あまり積極的には使いたくないなと思っていた。かといって直近に買ったほうは各キーが小さいから押しづらいし、誤作動することが前回判明した。

だから別のものを買うことを検討しないといけないかなあと思っていたんだが、ここで閃いた、というか思い出した。Netflix の映像はモニターに映していたんだけど、モニターと接続しているなら、モニター側にこのレシーバを取り付ければ、ダウンストリーム機能で Mac で使えるんじゃないかと。そして試してみたら、ビンゴ！ ちゃんと機能した！ というわけでレシーバ問題がなくなった旧エアマウス・キーボードが使えることが分かった。

とりあえず快適にリスニング練習ができる環境はある程度は整ったので、あとはこれをいかにして習慣化するかというところが求められる。今日は再契約初日だし、いろいろと試したいこともあって結果的に数時間やることができたが、いつもこのモチベーションが続くわけではもちろんないだろう。だから、それこそこの日記のやることリストに組み込んで、これから毎日、少しずつでも練習することを目標にしていくのが良いだろう。
